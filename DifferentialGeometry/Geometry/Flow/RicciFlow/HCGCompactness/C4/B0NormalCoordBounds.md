## The route (verbatim mathematical content)

Normal coordinates are NOT arbitrary coordinates: they are generated by `exp`, so the
coordinate vector fields are Jacobi fields, whose ODE coefficients ARE the curvature.
Curvature (and ∇^q Rm) bounds therefore convert into ordinary ∂-bounds of `g_{ij}`
by ODE estimates.

Fix `p`, identify `T_pM ≃ ℝⁿ` by an orthonormal basis, set `Φ(x) = exp_p(x)` on
`B_ρ(0)`, ASSUMED a normal chart on this ball. With `γ_x(t) = exp_p(tx)`:

- `J_i(t,x) := ∂_s|₀ exp_p(t(x+s eᵢ))` is a Jacobi field along `γ_x`:
  `D_t² J_i + R(J_i, γ̇_x)γ̇_x = 0`, `J_i(0,x) = 0`, `D_t J_i(0,x) = eᵢ`;
  and `J_i(1,x) = d(exp_p)|_x(eᵢ) = ∂_i|_{exp_p x}`.
- Hence `g_{ij}(x) = ⟨J_i(1,x), J_j(1,x)⟩`.
- Pull back through the parallel orthonormal frame `P_{t,x}` along `γ_x`:
  `Y_i(t,x) := P_{t,x}⁻¹ J_i(t,x)` satisfies `Y_i'' + A(t,x) Y_i = 0` with
  `A(t,x)Y = P⁻¹(R(PY, γ̇)γ̇)`, `γ̇(t) = P_{t,x} x`, so `‖A(t,x)‖ ≤ C₀|x|²`.
- Differentiate the ODE in `x` repeatedly: `∂_x^α Y_i` satisfies the linear
  inhomogeneous ODE `(∂_x^α Y_i)'' + A ∂_x^α Y_i = F_α`, where `F_α` contains only
  ∇^{≤|α|}Rm (through ∂_x^β A, which involves curvature derivatives and parallel-
  transport variation) and lower `∂_x^β Y_i`.  Induction on |α| + Grönwall:
  `‖∂_x^α Y_i(t,x)‖ ≤ C(n, ρ, C₀, …, C_{|α|})`.
- `g_{ij}(x) = ⟨Y_i(1,x), Y_j(1,x)⟩` (P orthogonal) ⟹ `|∂^α g_{ij}| ≤ C̃_α`.

Sanity (Taylor at the centre): `g_{ij} = δ_{ij} − ⅓R_{ikjl}x^k x^l − ⅙∇_mR_{ikjl}x^kx^lx^m + O(|x|⁴)`,
so `∂g(0) = 0`, `∂²g(0) ~ Rm(p)`, `∂³g(0) ~ ∇Rm(p)` — the Jacobi argument globalizes
this from the centre to the whole fixed-radius ball.

**Caveat (uniform radius):** curvature bounds alone do NOT give a uniform normal
radius; for a uniform `ρ` across points/manifolds one needs `inj ≥ i₀ > 0`
(bounded geometry: `|∇^q Rm| ≤ C_q` + `inj ≥ i₀`, then for each `ρ < i₀` uniform
`|∂^α g_{ij}| ≤ C̃_α`).  In this project: the `inj ≥ i₀` side is the Step A inputs +
`lambda_hasInjRadiusAt` (λ-balls ⊆ inj radius); "B_ρ(0) is actually a chart" at that
scale = the lbl383 item-3 frontier (exp injective-on-eball + local diffeo ⟹ ball
diffeo — `injOn_expMap_eball_of_lt_injRadius` is the injectivity half).

1. **ODE brick (zero geometry, zero collision):** second-order linear ODE norm bound
   over Mathlib Grönwall: `Y'' + A(t)Y = F`, `‖A‖ ≤ K` ⟹ first-order system bound
   `‖(Y,Y')(t)‖ ≤ (‖(Y,Y')(0)‖ + ∫‖F‖)·e^{max(1,K)t}`. Reusable for every induction
   step. (Mathlib may nearly have the first-order form.)
2. **Jacobi layer:** `IsJacobiAlong γ J` predicate on AlongCurve; the exp-variation
   `J_i(t,x)` is Jacobi (from geodesic-variation machinery); endpoint identification
   `J_i(1,x) = d(exp_p)_x eᵢ`; `g_{ij}(x) = ⟨J_i, J_j⟩(1)` (= metric pullback formula).
3. **Parallel transport layer:** existence + isometry + smooth x-dependence of
   `P_{t,x}` (itself a linear ODE along γ_x; existence via Picard–Lindelöf on the
   frame bundle chartwise). The heaviest stage.
4. **The induction:** pulled-back ODE for `Y_i`; `‖A‖ ≤ C₀|x|²`; differentiate in x;
   `F_α` bookkeeping (∇^qRm + P-variation + lower Y's); Grönwall via stage 1;
   conclude `|∂^α g_{ij}| ≤ C̃_α` on the chart.
5. **Wiring:** per-manifold uniformity over the Step A balls (lambda_hasInjRadiusAt +
   item-3 chart-scale when available); feeds B1.
