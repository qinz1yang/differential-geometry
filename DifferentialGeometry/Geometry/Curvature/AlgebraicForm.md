# AlgebraicForm

## Role

This is the pure algebra producer used by the positive Killing--Hopf route.
It records the polarization fact that an algebraic curvature form is
determined by its sectional diagonal.

## Reference alignment

The proof architecture follows the small algebraic core in the external
Poincare-Conjecture project's `DoCarmoCh4Sectional.lean`, adapted to the
RicciFlower convention and reduced to the API needed here.  No external module
is imported.
