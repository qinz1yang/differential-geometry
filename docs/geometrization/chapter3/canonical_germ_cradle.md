# Canonical local germ angles and actual cradle steps

Fourteen public theorems and one definition connect ALG01 to the geometric
construction in ALG02. The canonical germComparisonAngle is the actual
limsup of the two-parameter comparison-angle function along the product of
positive neighborhood filters at zero. It uses no arbitrary selected radius.
For specified minimizing germs in a local four-point neighborhood, the
function has this value as its actual joint limit. In a common comparison
domain it equals the previously proved positive-rectangle supremum.

The value always lies in [0,pi] and is symmetric. Curves agreeing on any
positive initial intervals have identical values, regardless of their values
outside those intervals. An actual minimizing germ has self-angle zero;
opposite germs have angle pi. Local four-point comparison implies the three-
germ sum bound and the adjacent sum bound. The full segments need not remain
inside the comparison neighborhood: each germ is shortened in the proof.
The endpoint-based uniform small-hinge bound now uses the canonical value.
The definition is a limsup for arbitrary curves; only the stated minimizing
and local comparison hypotheses certify that it is a joint limit.

The metric cradle theorem constructs x' on the SAME supplied isometry segment
to the longer endpoint, at h=(2ell/3-a)/3. It proves ell/18<h<=2ell/9<b,
shortness of both auxiliary hinges, nonincrease of the arm sum, and actual
membership of x' in both endpoint balls of radius ell. A separate range
lemma proves that the ENTIRE supplied segment from a center to either endpoint
stays in both endpoint balls when the sum of arms is less than ell. This
range lemma applies also to new joins once the arm-sum bound is available.
These metric results do not assume curvature, completeness, dimension or a
global geodesic instance. Segment choices and the given local comparisons
remain explicit, as required by the frozen blueprint.
