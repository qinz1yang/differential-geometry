# Moving marked points in the same specified limit: full AC81

The public theorem starts with actual source-to-target pointed approximations f_i on radii tending to infinity and errors tending to zero, a complete specified target Y, and bounded source marked points c_i. If the images of these marked points converge to y, then the ORIGINAL source spaces pointed at c_i converge to the SAME Y pointed at y. No source completeness, properness, length structure, curvature or replacement limit is needed.

A natural whole-space extension evaluates f_i on its original closed-ball carrier and uses the old target basepoint outside that carrier. Its exact public evaluation theorem preserves every original carrier value. The growing-radius and bounded-mark hypotheses make the marked points eventually belong to those carriers, so early undefined values have no effect on the conclusion. Their eventual original radial distortion is exposed explicitly. If their source separations tend to d, continuity and that same distortion prove dist(y,q)=d.

For each requested radius s and error alpha, the proof eventually has C+s<=R_i and3epsilon_i+2dist(f_i(c_i),y)<alpha<s. MC10 recenters the ORIGINAL map at c_i, AC77 repairs its target to exactly y, and error enlargement gives the actual required approximation. This proves all-radii/all-errors pointed convergence. Completeness is required only of Y here, as in the accepted pointed convergence convention.

If Y is proper, actual marked images eventually lie in the compact closed(C+1)-ball. The extraction theorem returns a point y of this SAME Y and a strictly increasing subsequence, convergence of the original mapped marks, pointed convergence at the original source marks, and the separation conclusion for EVERY converging source-separation sequence along that subsequence. In particular, separation one retains a distinct marked target point at distance one. The first target space and its maps are inputs; this result does not produce the first limit, cone structures or a two-apex line.
