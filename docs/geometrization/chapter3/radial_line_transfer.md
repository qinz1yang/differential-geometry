# One extraction of the supplied radial segments and same-map angle transfer

Five public theorems in three leaves preserve the actual original radial paths
through line extraction, pointed-map selection, and fixed-time distance/angle
limits. They supply the same-witness part of AC65/66; no new source curvature
or radial-segment existence theorem is assumed to have been produced here.

The radial engine takes actual growing-radius pointed ball approximations to
a proper target, a finite family of original opposite endpoints with possibly
pair-dependent lengths L_ij>0 tending to infinity, SUPPLIED radial isometries
qPlus/qMinus:[0,L_ij]->A_i with exact base and endpoint laws, and actual
absolute opposite excess tending to zero. Source spaces need only be metric.
It constructs signed prefixes Q_i on[-L_ij,L_ij] at EVERY original index,
retaining exact Q_i(+t)=qPlus_i(t) and Q_i(-t)=qMinus_i(t) in its public output.
It returns all four eta=0 calibration inequalities against the ORIGINAL positive
endpoints. Positive calibration is exact; negative calibration has precisely
the actual opposite excess. These same Q_i yield a finite family of actual
unit-speed target lines based at p and ONE strictly increasing subsequence,
with the SAME approximation maps converging uniformly on every fixed signed
interval. Radius control remains a separate output even for an empty family.

The pointed-convergence wrapper needs only the specified proper pointed target
and original PointedGHConverges. It selects actual approximations on a strict
diagonal, applies the radial engine to the reindexed SUPPLIED qPlus/qMinus,
and returns their single composed subsequence psi, actual R/epsilon/f/Q/gamma,
the original pointed convergence on psi, all exact qPlus/qMinus alignments at
psi_i, eta=0 calibrations, and same-map uniform convergence. It never replaces
the original radial family or selects another family for a later angle proof.

The independent continuity layer first proves source-distance convergence from
convergence of the two actual PBA images. This works over any index/filter,
without properness or geometric hypotheses. A second theorem consumes the
actual Q/f uniform convergence and proves cross-distance convergence at any
fixed signed parameters s,t, using the SAME maps and prefixes. IccExtend only
makes early indices total: eventual membership in each original signed domain
and each original approximation ball is derived before rewriting its values.
The third theorem gives convergence of comparison angles with arms |s|,|t|,
for nonzero s,t and kappa_i->0 eventually nonnegative. It uses the accepted
zero-curvature model-angle continuity theorem, and does not assume source
curvature, target comparison, target line isometry, or a new extraction.
