# Full AC47 metric classification: existence, exclusivity and parameters

Twelve public theorems in three leaves prove separation of the five metric
model types and assemble it with original-input pointed model existence.
The accepted parameter-rigidity theorems complete AC47's pointed conventions.

The separation results use the actual endpoint predicate and bounded distances.
A real line or closed ray cannot embed isometrically in any metric space
whose pairwise distances share a finite upper bound. Endpoints exclude ray/
line, interval/line, ray/circle and interval/circle isometries; boundedness
excludes line/circle and ray/interval. A subsingleton is nonisometric to each
of the four nontrivial types, using actual pairs at positive distance. All
positive segment/circle lengths are quantified, not fixed beforehand.

The public one_dimensional_model_types_pairwise theorem states that the five
actual model-existence propositions on ANY given metric space are pairwise
incompatible. It uses Lean's ordinary List.Pairwise relation on the explicit
five-element list, with relation 'not(A and B)'. Thus it asserts precisely
all TEN pairwise exclusions, not uniqueness of a chosen enumeration, chart
or coding. No curvature or model classification is assumed in this theorem.

The headline pointed_one_dimensional_classification assumes complete original
metric length geometry, global nonnegative four-point comparison, dimH<=1,
and a chosen basepoint. It returns BOTH the five actual pointed onto metric
isometry alternatives AND pairwise incompatibility of the unpointed types.
Exactly one type therefore occurs. The previous rigidity results prove the
positive interval/circle parameter unique, ray height unique and interval
basepoint coordinate unique up to reflection. Line/circle basepoints can be
centered at zero. This completes AC47 in the written metric scope. It also
finishes the recognition input used by the accepted original-global AC48
product assembly. No smooth structure is asserted.
