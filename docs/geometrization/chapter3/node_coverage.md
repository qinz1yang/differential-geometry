## Why the remaining producers are separate

MC17 and MC20 require concrete migrated PC Riemannian definitions and theorems.
This branch intentionally does not edit the old foundation or invent a second
manifold/metric API while Ziyang migrates it. The next integration work must
bind the accepted new release and prove the actual chart-domain and metric
transports against its signatures.

MC18 additionally consumes Chapter4's Alexandrov theorems. AC38--AC40's
metric/measure dimension argument and AC34/35/37's comparison limit argument
are now proved under their explicit source inputs. The remaining geometric
producers must establish the quantitative nets and ambient source comparison
on the actual carriers. Qualitative metric compactness alone still supplies
neither input.

The new combined consumer is
`GC.MetricGeometry.exists_geodesic_pointedGHConverges_of_covering_and_comparison`.
It constructs one complete proper pointed limit and proves its dimension
bound, exact metric segments, global nonnegative four-point comparison, and
the quadratic side inequality on that same limit. It imposes no completeness
or properness on the sources. The source comparison premise requires only
an eventual bound for each fixed radius, not a common tail for all radii.

Consequently `full_chapter_complete` remains false. The independent metric
work is available for absorption now; the full geometric application layer
is not being reported as finished, and the inherited Geometrization skeleton
has not become an unconditional proof as a consequence of these additions.
