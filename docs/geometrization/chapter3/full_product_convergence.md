# Full product convergence with both original maps: AC74

The controlled core keeps an arbitrary supplied sequence of actual source-to-target pointed ball approximations on radii tending to infinity with errors tending to zero. For one original whole-source KL product map it obtains actual factor approximations, a proper complete factor limit and an onto pointed product isometry on the SAME specified target. Every fixed source ball gets an explicit bound placing the original transverse image in the returned factor-map domain, followed by full product convergence. The Euclidean component is the original coordinate, the transverse component is the actual returned factor map applied to the original transverse coordinate. Its domain proof may be chosen arbitrarily; no arbitrary extension or proof-dependent map value is hidden.

The two-product theorem applies the same one-product construction to the two ORIGINAL maps in succession. The second construction takes the existing f subsequence. Both full estimates survive on the composed subsequence; the first factor maps are reindexed and the second are retained. Both limit isometries have the SAME target Y as domain. No independent replacement of the source-to-target maps occurs. The source and both approximating factor sequences require only metrics; only the fixed first factors E,F and the specified target Y are proper. Thus all finite Euclidean ranks, including zero and equal ranks, are covered. The first factors may be different proper metric spaces, a stronger metric scope than the Euclidean-rank source formulation. No source curvature, source completeness, approximating-factor properness, or coordinate continuity is used.

The explicit source-map preservation is stronger than the earlier accepted scalar-only AC51 conclusion. The new evaluation and radius lemmas expose its existing actual productLimitApprox construction without altering it. Padded factor domains, original map carriers and all extraction indices are retained in the public conclusion.

The final PointedGHConverges-only wrapper discharges the supplied-map hypothesis. It selects an initial subsequence beta carrying actual source approximations on radii i+1 with errors 1/[100(i+1)], then uses the two-product theorem. If that theorem selects alpha, the final original-source indices are beta composed with alpha, while the retained source radii/errors are indexed by alpha. The conclusion exposes these actual source maps and both actual factor-map sequences, with all six growth/error limits and the full paired uniform estimates. Thus the original AC74 pointed-convergence hypothesis suffices. No source-map identity is assumed.
